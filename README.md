# Chenzhe Zhang — Academic Website

Personal academic website built with Hugo Blox and deployed to GitHub Pages.

## Local preview

```bash
hugo server -D
```

Open `http://localhost:1313/` while the server is running.

## Content

- Home profile: `content/en/_index.md`
- CV page: `content/en/experience.md`
- Research overview: `content/en/research/_index.md`
- Research projects: `content/en/publications/`
- Profile data: `data/authors/`
- Downloadable files: `static/files/`

Pushing the `main` branch triggers the GitHub Pages deployment workflow.
